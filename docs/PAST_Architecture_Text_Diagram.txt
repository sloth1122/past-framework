KEY DESIGN PRINCIPLES:

1. PRE-TRADE GATE: Judge evaluates BEFORE execution → no forced same-day exits
2. COGNITIVE DIVERSITY: 3 models (GLM-5.2, Deepseek R1, Claude) → no single-model bias
3. SEPARATION OF POWERS: Judge runs on different model from traders → independence
4. TRUST REGION STABILITY: ±1 per trait per cycle → prevents wild oscillation
5. ICLE (In-Context Log Exploitation): Agents read own execution history at start
6. GTC STOP-MARKET ORDERS: Automatic execution when price hits stop → no agent needed
7. ZERO HUMAN INTERVENTION: System runs autonomously 7 days/week
